Image prompts for the studio.

73 images, one tap to copy each. Paste into Gemini (Nano Banana), generate, save with the exact filename shown. Each prompt already specifies its aspect ratio.

How to use

1. Tap the file pill to copy the filename, then tap Copy prompt.

2. Open Gemini app on your phone. Paste the prompt. Generate.

3. Save the image with the filename shown (it’s OK if the phone saves it as .jpg or .png — keep the rest of the name identical, we’ll convert to .webp after).

4. Store every image inside one folder called nirman-assets. Send the folder back when done.

5. Tap Done on a card to mark it finished — progress is saved on this phone.
